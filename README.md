## 📌 Lab Overview
This repository contains documentation, script outputs, and calculation notes for Lab 1A. The objective of this practical exercise was to master foundational data representation concepts critical for digital forensics, ensuring examiners can manually decode raw binary, hex, text, and time artifacts.

## 🛠️ Tools & Environment Used
* **Operating System:** Windows 11 / Linux VM (Command Line & Python)
* **Verification Tools:** Python interactive interpreter, standard terminal hashing utilities

## 📂 Key Sections Covered
1. **Number Systems & Conversions:** Performed manual and programmatic conversions between Decimal, Binary, and Hexadecimal values.
2. **ASCII & String Encoding:** Decoded raw ASCII and hex byte sequences into readable forensic strings.
3. **Timestamp Decoding:** Converted Unix Epoch timestamps and Mac Absolute Time values into human-readable UTC calendar dates.
4. **Cryptographic Hashing:** Evaluated file integrity using MD5/SHA-256 hashes and tested byte-level sensitivity (demonstrating how trailing newlines alter hash outputs).
5. **Data Endianness:** Analyzed byte-ordering differences (Little-Endian vs. Big-Endian) in memory structures.
